## 香港 CN2 GIA 比美西同线路贵，贵在三个地方

贵在机房位置、端口带宽和线路完整度这三项。CN2 GIA 对应 AS4809，是中国电信的精品骨干网；AS9929 是中国联通精品国际线路，晚高峰比普通 4837 线路稳；CMIN2 对应 AS9808，是中国移动国际网络。所谓“三网优化”，就是按访客所属运营商分流：电信走 CN2 GIA、联通走 9929、移动走 CMIN2。

单线便宜、三网全优化贵，这是同城机房内部的价差逻辑。只做电信优化，联通和移动访客晚高峰仍会绕路；三网都接精品线路，成本自然上去。买香港机器前先想清楚：访客里移动和联通占多少，值不值得为这部分人多付钱。
